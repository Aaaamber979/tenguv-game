# 声纹推理游戏 (TenguVox)

基于TenguVox声纹系统的推理游戏，玩家通过匹配时间片、场景、角色来解锁对话，还原故事真相。

## 功能特性

- 🎮 **场景平面图**: 可视化展示各个场景的位置关系
- ⏱️ **时间轴**: 按时间顺序显示不同时间段
- 🎙️ **声纹库**: 管理所有角色的声纹信息
- 🔍 **声纹匹配**: 拖拽角色到槽位进行匹配验证
- 💬 **对话解锁**: 正确匹配后解锁并显示对话内容
- ❓ **问答环节**: 完成推理后进行问答测试
- 💾 **数据持久化**: 自动保存自定义名称和解锁进度

## 技术栈

- React 18
- Vite
- CSS Modules
- HTML5 Drag and Drop API
- localStorage

## 游戏玩法

1. **设置角色名称**: 首次进入游戏时，为每个声纹设置自定义名称
2. **选择场景**: 点击场景平面图中的场景卡片
3. **选择时间**: 在时间轴上选择时间段
4. **匹配声纹**: 从声纹库拖拽角色到声纹槽位
5. **解析验证**: 点击"解析声纹"按钮验证匹配
6. **查看对话**: 匹配成功后查看解锁的对话内容
7. **回答问题**: 完成推理后进入问答环节测试你的理解

## 状态指示器

- 🟢 **绿色**: 待机状态
- 🟡 **黄色**: 解析中
- 🔵 **蓝色**: 匹配成功
- 🔴 **红色**: 匹配失败

## 自定义游戏数据

要创建自己的推理游戏，只需修改 `public/game.json` 文件：

1. 定义场景及其坐标
2. 添加角色（使用ID标识）
3. 创建时间线数据，包含每个时空的场景、时间段、正确答案和对话
4. 设计问答题目

所有剧情内容完全由JSON驱动，无需修改代码。
